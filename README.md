<details>
<summary><b>▸ LeadSite — o projeto que melhor me representa</b></summary>

<br/>

Ferramenta de prospecção B2B que **encontra empresas com problema de presença digital, prova o problema e monta a abordagem**. Roda inteira em serviços gratuitos.

| | |
|:--|:--|
| **Escala** | 12.280 linhas · 23 rotas de API · 14 telas |
| **Testes** | 82 casos em 5 suítes |
| **Stack** | Next.js 16 · TypeScript · Drizzle · Neon · Tailwind v4 |
| **Fontes** | OpenStreetMap · IBGE · Receita Federal · Gemini |

Três decisões que definem o projeto:

- **`nao-verificado` é diferente de `sem-site`.** Quando a fonte não traz o campo, isso não prova ausência — prova que ninguém preencheu. Confundir os dois faz você dizer "vi que vocês não têm site" pra quem tem.
- **A ferramenta se recusa a mentir.** No modo cliente oculto, se o teste mostrou que responderam em 4 minutos, ela **não gera** a mensagem sobre demora — avisa que o argumento não se sustenta.
- **Medir antes de construir.** O buscador de CNPJ só existe com validação de dígito verificador porque a medição mostrou que 5 de 6 números achados em sites reais eram falso positivo.

[`▸ ver repositório`](https://github.com/italocgouveia/leadsite)

</details>
